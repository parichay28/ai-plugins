# ai-plugins — agent instructions

- Prefer skills over commands: skills are the format Codex reads too.
- Plugins that wrap a CLI live in the CLI's own repo and are listed here with a `github` source pinned to a release tag (`"ref": "vX.Y.Z"`). Only skill-only plugins and self-contained mods (a hooks module with no CLI of its own) live in `plugins/`.
- Skills call CLIs through `bunx`/`npx` pinned to a major version; they don't bundle scripts.
- This repo is the only marketplace; other repos must not add a `marketplace.json`.
- Bump `version` in `plugin.json` on every behavior change and keep the marketplace entry's `version` in sync; tag `<plugin>--v<version>`. For external plugins, bump `ref` instead.
- Plan new plugins and features in `.ai-docs/plans/<name>.md` before building.
- Mods: `.claude-plugin/types/` is generated by Claude Code on load and gitignored; run `claude plugin test` as well as `validate`.
- Author/owner fields carry a name only, never an email.
- Tooling is bun: `bun run check` runs oxfmt, oxlint and tsc. UI component files are PascalCase (`ui/PreviewPane.tsx`); other files are kebab-case.
